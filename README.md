# 🗄️ MySQL Datenbankprojekt

## 📌 Über das Projekt

Dieses Projekt beschäftigt sich mit der Entwicklung, Verwaltung und Organisation relationaler Datenbanken mit MySQL.

Das Ziel ist es, praktische Kenntnisse im Bereich Datenbankmanagement und SQL-Abfragen zu vertiefen.

## ✨ Funktionen

- Datenbanken erstellen und verwalten
- Tabellen erstellen und bearbeiten
- Daten hinzufügen, aktualisieren und löschen
- SQL-Abfragen ausführen
- Tabellen miteinander verknüpfen
- Daten strukturiert speichern
- Daten effizient abrufen

## 🛠 Technologien

- MySQL
- SQL
- Relationale Datenbankverwaltung

## 📚 SQL-Kenntnisse

| SQL-Befehl | Beschreibung |
|---|---|
| CREATE | Datenbanken und Tabellen erstellen |
| INSERT | Neue Daten hinzufügen |
| SELECT | Daten abrufen |
| UPDATE | Daten aktualisieren |
| DELETE | Daten löschen |
| JOIN | Tabellen miteinander verbinden |
| WHERE | Daten filtern |
| ORDER BY | Daten sortieren |
| GROUP BY | Daten gruppieren |

## ⚙️ Installation und Verwendung

1. MySQL Server installieren.
2. MySQL Workbench oder ein anderes SQL-Tool öffnen.
3. Das SQL-Projekt importieren.
4. SQL-Abfragen ausführen.
5. Die Datenbank testen und verwalten.

## 🎯 Projektziel

Dieses Projekt dient dazu, praktische Erfahrungen mit relationalen Datenbanken zu sammeln und SQL-Kenntnisse weiterzuentwickeln.
